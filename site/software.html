Software

Foundation libraries and related software projects

Foundation Libraries

FAMLIES builds upon and extends these foundational libraries:

BLIS

Basic Linear Algebra Subprograms library

A portable, high-performance implementation of the BLAS API with a focus on architecture-aware performance. BLIS provides the micro-kernel layer that FAMLIES extends with algorithm selection and cross-layer fusion capabilities.

Language: C License: BSD
View on GitHub →

libflame

Formal Linear Algebra Methods Environment

An object-oriented library for dense linear algebra operations, supporting algorithm variants and auto-tuning. libflame demonstrates the principle of algorithm families that FAMLIES extends to the full software stack.

Language: C License: BSD
View on GitHub →

TBLIS

Tensor Basic Linear Algebra Subprograms

High-performance tensor contraction library designed for distributed-memory systems and GPU acceleration. TBLIS demonstrates how tensor operations can be integrated with linear algebra infrastructure, a key principle of FAMLIES.

Language: C++ License: BSD
View on GitHub →

Software Architecture & Integration

Layered Design

FAMLIES proposes a vertically integrated architecture that spans multiple layers:

  • Micro-kernels: Highly optimized compute kernels for specific hardware
  • BLIS Layer: Portable, high-performance BLAS implementation
  • libflame Layer: Dense linear algebra operations with algorithm selection
  • TBLIS Layer: Tensor operations and contractions
  • Application Layer: Scientific computing and machine learning frameworks

Key Principles

The FAMLIES framework is built on several core principles:

  • Vertical Integration: Elimination of rigid layer boundaries enables cross-layer optimization
  • Algorithm Families: Automatic selection of optimal algorithms for problem and hardware
  • Communication Awareness: Explicit control and reduction of data movement
  • Architecture Portability: Support for diverse hardware platforms without sacrificing performance
  • Consistent API: Unified programming interface across all layers

Future Development

The FAMLIES project includes plans for:

  • Extended GPU acceleration and support for emerging accelerators
  • Distributed-memory algorithms and multi-node optimizations
  • Enhanced tensor contraction capabilities
  • Integration with machine learning frameworks
  • Performance autotuning infrastructure
